# Portfolio de diseño

Sitio hecho con React y Vite.

## Desarrollo local

```sh
npm ci
npm run dev
```

## GitHub Pages

El sitio está configurado para el repositorio `portfolioDebi` y se publica
automáticamente al hacer push a `main`.

En GitHub, abrí **Settings → Pages** y elegí **GitHub Actions** como fuente de
despliegue. Una vez que termine el workflow, el sitio estará en:

https://decanatofcsupap-ctrl.github.io/portfolioDebi/
